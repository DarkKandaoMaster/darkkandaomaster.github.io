01桌面效率工具 · 持续维护

QuickSay

一款快捷短语软件

把常用的话、命令和 AI 提示词存进去，按 Ctrl+Shift+V 呼出，点一下就输入。支持分组、搜索、拖动排序和自定义快捷键。

最开始做它，只是为了方便发颜文字。后来发现，它可能是 Agent 时代最好用的 prompt 输入工具。

02日记编辑器 · 开发中

LineHush

只有纯文本和图片的日记编辑器

想要苹果备忘录那样的体验：敲几个回车就是几个空行，插进来的图片自动排成小图。Obsidian 和 VS Code 都不太对味，就自己写了一个。

  • 本地优先，一篇日记就是一个 .hush 文件
  • 停止输入后自动暂存，程序崩溃也能恢复
  • 粘贴或拖入图片，自动组成图片组
  • Tauri 2
  • React
  • TypeScript
  • Rust

Agent Skills 与补丁

给 AI 定的工作方法，和给工具打的小补丁。

  • Skill · Python★ 3 verified-web-research 约束 AI 联网搜索：检查链接能不能打开、网页内容是否真的支持它的说法、多篇转载有没有被当成多个来源。
  • Skill · Python stepwise-lessons 把一个知识点、一篇论文或一段讲座拆成给初学者的课程，一课一个文件，讲完一课就停下来等你反馈。
  • Skill · PowerShell★ 2 claude-session-migrate 换号之后，把 Claude 桌面应用里的旧会话找回来。
  • 补丁 · Python★ 1 slash-collapse-patch 给 VS Code 的 Claude Code 扩展打个补丁，让超长的斜杠命令消息变成滚动框，不再撑满整页。
